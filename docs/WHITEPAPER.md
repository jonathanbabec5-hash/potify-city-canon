# POTIFY City Public World Bible
## Whitepaper · public developer edition

**November 25, 2026 · Creative registry and searchable site**

### Goal and audience

Let players and contributors explore the city while keeping story discoveries intact. The immediate audience is world-builders, game fans and illustrators.

### Design and implementation

A public JSON registry feeds the searchable canon and exported guide. Design status is recorded per entry separately from playtest evidence. A stable feature ID supports discussion while story secrets remain with the author. A feature's design status can advance only with named implementation evidence.

### What a contributor can establish

The public registry contained 469 distinct IDs across 18 sections, and the public registry page loaded in a local Chromium session. A searchable registry is useful even when a mechanic is conceptual. Link a game revision and test result before assigning playable status.

### Evidence and outstanding work

The 469-entry public registry is a design record. The game runtime lives in the separate Potify repository. The next acceptance case is concrete. Select a feature by ID, identify its status and link a reproducible game result before calling it playable.

### Place in POTIFY

Test demand for a printable city field guide through opt-ins, then paid preorders only with deliverable art and terms. The marketing plan gives the test window and the evidence for a commercial outcome.
